First public release. Realistic cars, people and snakes; sound effects; buildings that collapse and cars that crash and dent. The in-car radio plays the game’s own synthesized station; no licensed music is included.

What “tested” means

“Launched and checked” means the developer started that exact file, entered a save code, loaded the world and found no errors. “Built, not yet tested” means the file was produced by the same build process but has not been run on that kind of computer yet. Please report problems.

Differences from development builds

Public downloads leave out the licensed songs used during development. The in-car radio plays the game’s own synthesized station instead.
