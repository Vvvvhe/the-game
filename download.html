These builds are not code-signed yet

Your computer may warn that the developer is unidentified. This is expected for unsigned games from independent developers. Only continue if you downloaded the file from this website, and check the SHA-256 checksum first if you can.

Windows

If Microsoft Defender SmartScreen says “Windows protected your PC”, select More info, then Run anyway.

macOS

Unzip the file and move Sunspot County.app to Applications. Open it. If macOS blocks it, open System Settings → Privacy & Security, scroll down and select Open Anyway.

Linux

For the AppImage, mark the file as executable (in a terminal: chmod +x Sunspot-County-*.AppImage), then run it. For the tar.gz, extract it and run the sunspot-odyssey program inside the folder.

Check that your download is intact

Compare the file’s SHA-256 checksum with the value listed next to the download. The full list is in SHA256SUMS.txt.

  • Windows (PowerShell): Get-FileHash .\Sunspot-County-1.0.1-Windows-Portable.exe
  • macOS (Terminal): shasum -a 256 Sunspot-County-1.0.1-macOS-arm64.zip
  • Linux: sha256sum Sunspot-County-1.0.1-Linux-x86_64.AppImage

Saves

Progress is saved on your computer under a five-digit code that you choose. Codes are not accounts and are never sent anywhere. Saves stay when you replace the game with a newer version.
